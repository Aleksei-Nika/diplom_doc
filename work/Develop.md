# Разработка
Разработка сервиса **"Assistent"** в его планируемом функционале разделена на несколько этапов, по завершению каждого которых сервис будет представлять собой продукт способный решать определенные задачи в полной мере. Данный подход позволит получить результат даже в случаи того, если проект не будет завершен в планируемом объеме.

Общие аспекты разработки взяты из [паспорта проекта](<../Project_passport.md>):
см. [проблематика](<../Project_passport.md#Проблематика>)
см. [задачи](<../Project_passport.md#Задачи>)

## Этапы разработки

### 1 этап - "Создание системы учета"
#### Решаемые проблемы
1. Отсутствие единой системы учета;
2. Неудобный способ анализа;
3. Долгий процесс учета.
#### Задачи этапа
1. Создание необходимой структуры сущностей и операций учета и чтения;
2. Реализация сценариев анализа данных;
3. Разработка интерфейса взаимодействия пользователя с системой.
**переход** [1 этап разработки](<./Develop_stage_1.md>)

### 2 этап - "Интеграция группового чата и AI-агента"
#### Решаемые проблемы
1. Долгий процесс учета;
2. Ручной ввод данных;
#### Задачи этапа
1. Интеграция информации из группового чата в систему учёта;
2. Автоматизировать интерпретация информации из чата с помощью AI-агента;
3. Реализовать механизм формирований предложений учётных операций на основе информации из чата;
4. Создать интерфейс проверки и подтверждения предложенных операций пользователем.
**переход** 2 этап разработки

### 3 этап - "Управление доступом и аудит действий пользователей"
#### Решаемые проблемы
Решает нефункциональные проблемы по безопасности
1. отсутствие разграничения доступа к данным и функциям системы;
2. отсутствие возможности установить, кто и когда изменил учётные данные;
3. недостаточный контроль действий пользователей.
#### Задачи этапа
1. Разработка ролевых моделей и сценариев для них;
2. Создание и интеграция сущностей в БД для  пользовательских профилей;
3. Реализация системы логирования действий пользователя по изменению данных учёта.
**переход** 3 этап разработки
