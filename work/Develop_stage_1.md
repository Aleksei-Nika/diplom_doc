# Разработка этап 1
**Создание системы учета**
Данных этап предполагая начала разработки проекта и заложение основ для дальнейшего добавления функционала в последующих этапах. Система учета представляет собой базу данных организованную из определенных сущностей, определенный набор операции по манипуляции с этими сущностями и интерфейс для вызова этих операций.
## Структура системы учёта
см. [структура](<../docs_project/Architecture.md#Структура сервиса "Этап 1">)
## Декомпозиция задач на технические задачи
см. [задачи 1 этапа](<./Develop.md#Задачи этапа>)
1. Создание базы данных с необходимой структурой;
2. Создание методов получения, создания, редактирования, удаления сущностей базы данных;
3. Создания методов для анализа данных;
4. Создание графического Web интерфейса для взаимодействия с базой данных;
5. Интеграция базы данных и интерфейса.

## База данных
При проектировании базы данных основные сущности определялись по [терминологии проекта](<../docs_project/Project.md#Терминология проекта>).
См. [База данных](<../docs_project/modules/backend/Data_base.md#Система учета>)

## Методы заполнения базы данных
### Asset "Материальные ценности"
См. [Asset - таблица "материальные ценности"](<../docs_project/modules/backend/Data_base.md#Asset - Таблица «Материальные ценности»>)
#### Создание
При создании Asset в базе данных нужно указывать:
- **Наименование** - уникальное значение для объектов;
- **Ед.Изм** - из заранее заданных;
- **Тип** - из заранее заданных;
- **Примечание** - необязательное поле
эндпоинт POST /asset
