# Устройство проекта "Assistant"

## Описание проекта:
Проект задуман как локальный WEB сервис для учета движения материальных средств, с автоматическим отслеживанием перемещений и поставок через групповой чат в мессенджере Telegram путём отслеживания контекста через AI агента.

> [!NOTE] ### Терминология: 
> ##### "Материальные ценности", "материальные средства" (группа сущностей)
>Общая категория всего, что учитывается в системе: у чего есть наименование, единица измерения, количество и место нахождения.
>##### "Материалы" (сущность)
>Материальные ценности, которые могут заявляться в потребности и поступать на объект. Их обычно учитывают как запас, который накапливается.
>##### "Оборудование", "оснастка" (сущность)
>Материальные ценности, для которых характерны многократные перемещения между объектами и повторное использование. В теории, в рамках сервиса, они могут бесконечно перемещаться между объектами.
>##### "Движение материальных ценностей" (группа операций)
>Любая операция, которая фиксирует поступление извне или внутреннее перемещение между объектами.
>##### "Поступление" (операция)
>Приход материальных ценностей на объект извне системы учёта внутренних перемещений.
>##### "Перемещение" (операция)
>Передача материальных ценностей с одного учитываемого объекта на другой внутри организации.
>##### "Учёт" (внесение данных)
>Фиксация операций движения в сервисе с возможностью восстановить состояние запасов на определённый момент.
>##### "Анализ" (просмотр данных с фильтрацией)
>Представление учётных данных, позволяющее получить определённый вывод: например, сопоставить заявленное количество материала с фактически поступившим.

Это базовое понятие, объединяющее материалы и оборудование.

## Путь реализации:
Для успешной реализации проекта принято решение разрабатывать сервис в три этапа:
1. Создать единый сервис для учета и анализа движения материальных средств с отображением;
2. Интеграция группового чата как точки входа информации с валидацией через стороннего AI агента и автоматическим предложением по фиксации движения материальных средств;
3. Добавление в сервис учетных профилей и ролей.
